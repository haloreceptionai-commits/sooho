Export Everything World zones to GLB

This runs the source world (Everything-World-3D.html, next to this page) in a hidden frame, exports each zone with three.js GLTFExporter, and downloads one GLB per zone plus manifest.json. Move the downloads into worlds/everything/. The file names match what the pipeline expects.

Serve this folder first, for example python -m http.server 8000 in worlds/source, then open http://localhost:8000/export_zones.html. Allow multiple downloads when the browser asks. An internet connection is needed for three.js (cdnjs and unpkg).
